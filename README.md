# tagy

A tree editor for tag-based markup: XML, HTML, and Markdown in one tree model.

Sibling of [confy](https://github.com/superyngo/confy) (key–value config formats); tagy
targets element + attribute trees instead. Early stage: no code yet. Scope and vocabulary are in
[CONTEXT.md](CONTEXT.md).
